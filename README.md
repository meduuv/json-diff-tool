# JSON Diff Tool

A dependency-free browser app that compares two JSON documents by flattened structural paths.

## Features
- Added, removed, changed, and unchanged values
- Nested object paths
- Array indexes
- Pretty-print and swap controls
- Runs entirely locally with no backend

## Usage
Open `index.html`, paste JSON into both panels, then click **Compare**.

The comparison is intended as a quick structural review. It does not attempt semantic equivalence beyond parsed JSON values.
